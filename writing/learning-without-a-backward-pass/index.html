Learning without a backward pass

Several published schemes drop the global backward pass. None of them yet does the whole job, and the honest position is to say which part each one leaves undone.

Mateo Hernandez · 12 August 2026

A gradient computed by traversing an entire system backwards forces the split between training and use. If learning is meant to continue for as long as a system is running, that traversal has to go.

Three archived attempts remove it in different ways. R005 replaces the backward pass with two forward passes and a local objective per layer. R006 reaches the same gradients by letting a network settle to equilibrium and reading the difference between two states. R009 shows that predictive coding, which is local by construction, approximates backpropagation along arbitrary computation graphs.

What each one still assumes#

R006 needs a relaxation to equilibrium before any update is valid, which is a global condition wearing local clothes. R009 approximates the very thing it was meant to replace, which makes it a proof of sufficiency rather than a departure. R005 keeps a hand-chosen objective per layer.

S002 is the one that looks least like the others. It reports experimental support for plasticity rules with three factors: a local coincidence, an eligibility trace that holds it for a while, and a modulatory signal that decides afterwards whether it counted. Nothing in that description requires a backward pass, and the trace is what closes the gap between when something happens and when it turns out to matter.
